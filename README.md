Python tool I build to track dress quotes, clients,fabrics and profits.
This project is part of my Data Analyst learning journey.

-ADD new quotes (clients, dress type, fabric, cost, price)
-VIEW all quotes with ID
-SEARCH by client name
-Auto-calculates profit (price - cost)
-SAVES to CSV for analysis

-Python, CSV module
-Data Cleaning (fixed 8 vs 9 column mismatch)
-GitHub for version control (build on mobile with Pydroid 3)

-Load CSV with Pandas 
-Monthly profit reports
-Top clients & most profitable fabrics
-Charts with Matplotlib
